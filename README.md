The one word I would erase from the dictionary forever: "irregardless" — a double negative wearing a tuxedo. The "ir-" prefix and the "-less" suffix both negate, so the word cancels itself out before it even starts meaning anything, and it adds nothing that "regardless" does not already say, cleaner. Delete it and the language loses nothing.
